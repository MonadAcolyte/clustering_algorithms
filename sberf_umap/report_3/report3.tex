\section{Macro-averaged Precision, Recall, and F-score}

For each cluster, precision is the proportion of points in that cluster belonging to its majority class, and recall is the proportion of all points of that class captured by the cluster. The F-score is their harmonic mean.

\subsection*{Cluster 1 (majority class: red)}
\[
P_1 = \frac{4}{10} = 0.4000 \qquad
R_1 = \frac{4}{8}  = 0.5000 \qquad
F_1 = \frac{2 \times 0.4 \times 0.5}{0.4 + 0.5} = 0.4444
\]

\subsection*{Cluster 2 (majority class: blue)}
\[
P_2 = \frac{5}{9}  = 0.5556 \qquad
R_2 = \frac{5}{10} = 0.5000 \qquad
F_2 = \frac{2 \times 0.5556 \times 0.5}{0.5556 + 0.5} = 0.5263
\]

\subsection*{Cluster 3 (majority class: purple)}
\[
P_3 = \frac{4}{8} = 0.5000 \qquad
R_3 = \frac{4}{9} = 0.4444 \qquad
F_3 = \frac{2 \times 0.5 \times 0.4444}{0.5 + 0.4444} = 0.4706
\]

\subsection*{Macro averages}
\[
\bar{P} = \frac{0.4000 + 0.5556 + 0.5000}{3} = 0.4852
\]
\[
\bar{R} = \frac{0.5000 + 0.5000 + 0.4444}{3} = 0.4815
\]
\[
\bar{F} = \frac{0.4444 + 0.5263 + 0.4706}{3} = 0.4804
\]

\section{B-CUBED Precision, Recall, and F-score}

B-CUBED computes precision and recall at the individual point level. For a point $i$ in cluster $C$ with class $L$:

\[
P(i) = \frac{|\{j \in C : L(j) = L(i)\}|}{|C|}
\qquad
R(i) = \frac{|\{j \in C : L(j) = L(i)\}|}{|\{j : L(j) = L(i)\}|}
\]

The overall B-CUBED scores are the averages over all points. The per-class contributions are shown below:

Each row's $P$ and $R$ values are weighted by $n$ (the number of points contributing that value). The overall averages across all 27 points are:

\[
P_{\text{B3}} = \frac{4(0.4) + 2(0.2222) + 2(0.25) + 3(0.3) + 2(0.2222) + 4(0.5) + 3(0.3) + 5(0.5556) + 2(0.25)}{27} = 0.3728
\]

\[
R_{\text{B3}} = \frac{4(0.5) + 2(0.25) + 2(0.25) + 3(0.3333) + 2(0.2222) + 4(0.4444) + 3(0.3) + 5(0.5) + 2(0.2)}{27} = 0.3712
\]

\[
F_{\text{B3}} = \frac{2 \times 0.3728 \times 0.3712}{0.3728 + 0.3712} = 0.3720
\]

\bigskip

Thus, for Macro-averaged values: Precision = 0.4852, Recall = 0.4815 and F-score: 0.4804.
